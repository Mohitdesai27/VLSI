# 3. 3-bit Up/Down Counter (Synchronous)

M = 1 ⇒ Up Count
M = 0 ⇒ Down Count

## Combined Excitation Logic

From Up Counter: 

  Q0​* = ~Q0

  Q1​* =Q1​⊕Q0​

  Q2* =Q2⊕(Q1⋅Q0)

From Down Counter: 

  Q0* = ~Q0

  Q1* = Q1⊕Q0

  Q2* = Q2⊕(Q1Q0)
  
## Merge Using Control Input M

Q0*​ = ~Q0

Q1* ​= Q1 ​⊕ (Q0​ ⊕ ~M)

Q2* ​= Q2 ​⊕ [(Q1 ⊕ ~M) (Q0​ ⊕ ~M)]
